## Launch
Open `index.html` locally. For GitHub Pages, upload the **contents** of this folder to the root of a public repository, then enable Settings → Pages → Deploy from a branch → main → /(root).

This is a static site; no backend is required. Command availability depends on installed packages. No commands are executed by the website.
